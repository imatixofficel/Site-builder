# Site Builder (سایت‌ساز) - Claude skill

## نصب
1. این پوشه (`site-builder`) رو زیپ کن یا همین فایل زیپ رو نگه دار.
2. Claude -> Settings -> Capabilities -> Skills -> Upload skill رو بزن و زیپ رو انتخاب کن.

## قبل از استفاده
- عکس‌های مرجع و عکس‌های سایت رو داخل پوشه `image/` بذار.
- فایل فونت‌ها رو داخل پوشه `fonts/` بذار.
- (بعد از اضافه کردن فایل‌ها دوباره زیپ کن و آپلود کن.)

## استفاده
بنویس: «برام یه سایت بساز». اسکیل به ترتیب می‌پرسه: سبک کار -> (رنگ خودکار) -> فونت -> اسم سایت -> لوگو -> ساخت سایت و سوال‌های بهتر شدن.
خروجی: یک فایل html که با دوبار کلیک تو مرورگر باز می‌شه.
