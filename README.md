# Site Builder (سایت‌ساز) - Claude skill

## نصب / به‌روزرسانی
1. پوشه `site-builder` را زیپ کن (همه چیز داخل پوشه، فونت‌ها و عکس‌ها هم).
2. Claude > Settings > Capabilities > Skills > Upload skill و زیپ را انتخاب کن.
3. بعد از افزودن عکس یا فونت جدید، دوباره زیپ و آپلود کن.

## چه چیزهایی داخلش است
- `image/` عکس‌های مرجع استایل و عکس‌های قابل استفاده در سایت
- `fonts/` فونت‌ها (وزیر، ساحل، صمیم، شبنم، تنها، پرستو، یکان و ...)
- `templates/` موتورهای آماده و امن (PHP با پنل مدیریت، قالب وردپرس، افزونه امنیتی، .htaccess)
- `scripts/` ابزارهای کم‌مصرف برای اسکن عکس‌ها، فونت‌ها و ساخت زیپ‌های آماده هاست
- `references/` راهنماهای داخلی (سوال‌ها، رنگ‌ها، امنیت، قالب)

## استفاده
بنویس: «برام یه سایت بساز». به ترتیب می‌پرسد: سبک کار > (رنگ خودکار) > فونت > اسم سایت > لوگو > نوع تحویل > ساخت سایت > سوال‌های بهتر شدن.

نوع تحویل:
1. یک فایل HTML (دوبار کلیک)
2. زیپ آماده آپلود روی هاست (HTML ساده)
3. سایت PHP با بک‌اند و پنل مدیریت (نصب با مرورگر، پنل `/admin/`)
4. قالب وردپرس + افزونه امنیتی

برای هر نوع، یک فایل راهنمای فارسی (`...-GUIDE-FA.txt`) کنار زیپ‌ها تحویل می‌شود. فایل راهنمای نسخه PHP «کد نصب» دارد؛ آن را فقط روی کامپیوتر خودت نگه دار و روی هاست آپلود نکن.

## امنیت (خلاصه)
هدرهای امنیتی و CSP، محافظ .htaccess، رمز هش‌شده، قفل بعد از ۵ تلاش ناموفق، ورود دو مرحله‌ای، توکن CSRF، آپلود امن تصویر، فرم تماس ضد اسپم، افزونه امنیتی وردپرس و صفحه وضعیت امنیت.
بقیه (SSL، رمز قوی، بکاپ، به‌روزرسانی) کار صاحب سایت است و در راهنما نوشته شده.
