# پوشه image / Images folder

اینجا عکس‌ها رو بریز؛ اسکیل خودش تشخیص می‌ده کدوم مرجع استایله و کدوم عکس برای داخل سایت.

- **عکس مرجع استایل** (اسکرین‌شات سایت/اپ/پوستر که دوست داری سایت شبیهش بشه): اسکیل رنگ، گردی گوشه‌ها، سایه/شیشه‌ای بودن، چیدمان و فونت‌نما رو ازش یاد می‌گیره.
- **عکس‌های قابل استفاده در سایت** (محصول، غذا، آدم‌ها، مکان‌ها، بک‌گراند): مستقیم داخل سایت استفاده می‌شن.
- می‌تونی زیرپوشه بسازی، مثلاً `style/` برای مرجع‌ها و `photos/` برای عکس‌های سایت؛ ولی لازم نیست.
- فرمت‌های مجاز: png, jpg, jpeg, webp, gif. اسم فایل‌ها رو انگلیسی و بدون فاصله بنویس.

Drop style references (screenshots of designs you like) and photos to be used in the site here. Subfolders are optional.
