راهنمای آپلود سایت «{{NAME}}» روی هاست (نسخه HTML ساده)
=========================================================

  1) وارد پنل هاست (cPanel یا DirectAdmin) > File Manager > پوشه public_html شوید.
  2) فایل زیپ را آپلود کنید و Extract بزنید؛ فایل index.html باید مستقیماً داخل public_html باشد.
  3) آدرس دامنه را باز کنید؛ سایت آماده است.

امنیت
  [ ] SSL رایگان را از پنل هاست فعال کنید، بعد در فایل .htaccess سه خط «Force HTTPS» را از حالت توضیح (#) دربیاورید.
  [ ] فایل .htaccess همراه سایت هدرهای امنیتی، بستن لیست پوشه‌ها و فشرده‌سازی را فعال می‌کند (فقط روی Apache/LiteSpeed).
  [ ] رمز پنل هاست قوی و یکتا باشد و ورود دو مرحله‌ای پنل هاست را روشن کنید.
  [ ] از فایل‌های سایت بکاپ نگه دارید.

توجه: نسخه HTML ساده پنل مدیریت و دیتابیس ندارد. اگر می‌خواهید خودتان متن و عکس را عوض کنید، نسخه «PHP + پنل مدیریت» یا «وردپرس» را درخواست بدهید.
