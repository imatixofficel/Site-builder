راهنمای نصب سایت «{{NAME}}» روی هاست (نسخه PHP + پنل مدیریت)
==============================================================

کد نصب شما (فقط برای مرحله نصب لازم است):   {{KEY}}

پیش‌نیاز هاست: PHP نسخه 7.4 یا بالاتر (بهتر: 8.1+) و Apache یا LiteSpeed (هاست‌های cPanel / DirectAdmin).

مرحله ۱ - آپلود
  1) وارد پنل هاست شوید (cPanel یا DirectAdmin) و File Manager را باز کنید.
  2) وارد پوشه public_html (یا پوشه همان دامنه) شوید.
  3) فایل زیپ را آپلود کنید و روی آن Extract بزنید. باید فایل‌های index.php و install.php و پوشه‌های admin، inc، data، theme، assets، uploads مستقیماً داخل public_html دیده شوند (نه داخل یک پوشه اضافه).
  4) فایل .htaccess را هم ببینید (در File Manager گزینه Show Hidden Files را روشن کنید).

مرحله ۲ - نصب (۲ دقیقه)
  1) در مرورگر باز کنید:   https://دامنه-شما/install.php
  2) در صفحه، تیک پیش‌نیازها باید سبز باشد. کد نصب بالای همین فایل را وارد کنید.
  3) نام کاربری و یک رمز قوی (حداقل ۱۰ نویسه، شامل حرف و عدد) بسازید.
  4) دیتابیس: «SQLite» ساده‌ترین است و نیاز به تنظیم ندارد. اگر MySQL خواستید، اطلاعاتش را از بخش MySQL Databases هاست بگیرید.
  5) اگر سایتتان پشت Cloudflare است، تیک مربوطه را بزنید.
  6) «نصب کن» را بزنید. بعد از نصب خودکار به پنل مدیریت می‌روید و فایل install.php پاک می‌شود. اگر پاک نشد، خودتان از File Manager حذفش کنید.

مرحله ۳ - پنل مدیریت
  آدرس:  https://دامنه-شما/admin/
  از پنل می‌توانید متن‌ها، رنگ‌ها، عکس‌ها، لیست‌ها (خدمات، محصولات، گالری و ...) را عوض کنید، پیام‌های فرم تماس را بخوانید و رمز عبور را تغییر دهید. بدون هیچ کدنویسی.

مرحله ۴ - امنیت (حتماً انجام دهید)
  [ ] SSL رایگان را در هاست فعال کنید (در cPanel: SSL/TLS Status یا AutoSSL).
  [ ] بعد از فعال شدن SSL، در فایل .htaccess سه خطی را که زیرش نوشته «Force HTTPS» است از حالت توضیح (#) دربیاورید تا همه چیز HTTPS شود.
  [ ] از پنل مدیریت > «امنیت و رمز عبور» ورود دو مرحله‌ای (Google Authenticator) را روشن کنید.
  [ ] هرگز رمز را برای کسی نفرستید و از رمز تکراری استفاده نکنید.
  [ ] هر ماه از پوشه‌های data و uploads بکاپ بگیرید (File Manager > Compress > دانلود). همه اطلاعات سایت در همین دو پوشه است.
  [ ] نسخه PHP هاست را به‌روز نگه دارید.

چه چیزهایی از قبل در سایت فعال است؟
  - رمز عبور با هش امن ذخیره می‌شود. بعد از ۵ تلاش ناموفق، ۱۵ دقیقه قفل می‌شود.
  - همه فرم‌ها توکن CSRF دارند و دیتابیس فقط با دستورهای امن (Prepared Statement) کار می‌کند.
  - خروجی‌ها escape می‌شوند (جلوگیری از XSS) و هدرهای امنیتی (CSP، HSTS، X-Frame-Options و ...) ارسال می‌شود.
  - آپلود تصویر: فقط JPG/PNG/WebP/GIF، بازنویسی امن تصویر، اسم تصادفی، و اجرای هر اسکریپت در پوشه uploads بسته است.
  - پوشه‌های data، inc و theme از بیرون قابل دسترسی نیست. فرم تماس ضد اسپم (honeypot + محدودیت تعداد) دارد.
  - نشست ورود: کوکی امن، قفل به مرورگر، خروج خودکار بعد از ۳۰ دقیقه بی‌کاری.

مشکل داشتید؟
  - صفحه سفید یا خطا: فایل data/error.log را باز کنید و متن آخر آن را برای سازنده بفرستید.
  - قفل شدن بخاطر ورود دو مرحله‌ای (گوشی گم شد): با File Manager داخل پوشه data یک فایل خالی به نام DISABLE_2FA بسازید و یک بار با رمز وارد شوید.
  - اگر هاست شما Nginx است (نه Apache/LiteSpeed)، فایل .htaccess اثر ندارد؛ از پشتیبانی هاست بخواهید دسترسی به پوشه‌های data و inc و theme را ببندد.
  - برای تغییر طراحی یا افزودن بخش جدید، به همان گفتگو با Claude برگردید و بگویید چه چیزی عوض شود.
