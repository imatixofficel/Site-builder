# پوشه fonts / Fonts folder

فایل فونت‌ها رو اینجا بذار: woff2 (بهترین)، woff، ttf یا otf.
اسم فایل‌ها نوع وزن رو داشته باشه، مثلاً `Vazirmatn-Regular.woff2` و `Vazirmatn-Bold.woff2`.
فقط فونت‌هایی بذار که اجازه استفاده‌شون رو داری (فونت‌های آزاد مثل Vazirmatn، Estedad، Shabnam).

Put font files here (woff2 preferred, also woff/ttf/otf). Name files with their weight, for example `Vazirmatn-Bold.woff2`.
