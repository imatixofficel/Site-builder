# Question bank (Persian first, English in parentheses)

Ask one question at a time. Prefer tappable options. Keep each question to one or two lines. Skip any question the user has already answered.

## Step 1 - Work style
Question: «سایتت برای چه کاری هست و چه حال‌وهوایی می‌خوای؟» (What is the site for, and what look do you want?)

If you can only ask one question, ask the look, and infer the field from the first message.

Field options (pick the 4 most likely, plus "دیگر"):
- فروشگاه آنلاین (online shop) | رستوران / کافه (restaurant, cafe) | کلینیک / پزشکی (clinic)
- نمونه‌کار / پورتفولیو (portfolio) | شرکت / خدمات (company, services) | آموزش / دوره (education)
- برند شخصی (personal brand) | وبلاگ / خبر (blog, news) | رویداد (event) | معرفی اپلیکیشن (app landing)

Look options (always 3):
1. «همان سبک عکس‌های مرجع» - describe the learned style in 4-8 plain words (for example "شیشه‌ای، نرم، گرد و تیره").
2. A contrasting option that suits the field (for example "مینیمال و روشن").
3. A third option with different energy (for example "پررنگ و جسور").

## Step 3 - Font
Question: «کدوم فونت رو برای سایت می‌خوای؟» (Which font do you want for the site?)

Options (3-4):
1. Font that matches the reference images (name it, say "شبیه عکس‌های مرجع").
2. Best family bundled in the fonts folder (name it).
3. One more suitable for the field (name it).
4. «فونت دیگر / فونت خودم»

## Step 4 + 5 - Name and logo (one message)
«اسم سایت چیه؟ 
اگه لوگو داری همین‌جا بفرست؛ اگه نداری بنویس «بدون لگو» تا بدون لوگو بسازم.»
(What is the site name? If you have a logo, send it now; if not, write "no logo" and I will build without one.)

## Step 6c - Improvement questions (max 3 at once)
Choose the ones that matter most for this site:
- «اطلاعات واقعی رو بدی؟» - phone, address, working hours, Instagram/Telegram/WhatsApp, services or products with prices.
- «چه بخشی اضافه یا حذف بشه؟» - testimonials, FAQ, gallery, pricing, blog, contact form, map.
- «ظاهر رو چطور تغییر بدم؟» - lighter/darker, rounder/sharper, calmer/bolder, other palette or font.
- «مهم‌ترین کار بازدیدکننده چیه؟» - call, order, book, message, sign up.
- «نسخه انگلیسی یا دو زبانه هم لازم داری؟»

After the answer, apply one change at a time and report only what changed.
